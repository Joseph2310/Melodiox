# Diminished chord inversions

These 96 keyboard diagrams were generated locally from the chord notes documented in the parent folder. They are not downloaded PianoChord.org images.

## Included diagrams

- `diminished_triad/first/`: 12 first inversions (`b3-b5-1`)
- `diminished_triad/second/`: 12 second inversions (`b5-1-b3`)
- `diminished_7/first/`, `second/`, and `third/`: 36 fully diminished seventh inversions
- `half_diminished_7/first/`, `second/`, and `third/`: 36 half-diminished seventh inversions

Each image shows one ascending, close-position voicing across a two-octave keyboard. Red keys are the notes to play, and the leftmost red key is the bass note that defines the inversion.

`inversion_data.csv` lists the slash-chord symbol, bass note, ordered notes, and local path for every diagram.
