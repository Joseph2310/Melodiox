# Melodiox

Melodiox is a personal music library app for organizing songs, lyrics, media, playlists, notes, rhythms, scales, chords, and piano-learning material in one place.

The app is designed for practice, rehearsal, church service preparation, and quick access during live use.

## Main Sections

### Songs

The Songs section is the main library for all saved songs. Each song can include:

- Title
- Lyrics
- Notes
- Original key
- Your key
- Transpose value
- Original scale and your scale
- BPM / tempo
- Quarter-toned keys
- Tags
- Rhythm items
- Chords
- Chord images
- Melody images
- Audio files
- Vocal-only audio
- Performance videos
- External media links

You can search, sort, filter, favorite, edit, delete, and bulk-select songs.

### Favorites

Favorites gives you fast access to songs you use often. A song can be marked or unmarked as favorite from its details.

### Playlists

Playlists help group songs for services, rehearsals, lessons, or events.

You can:

- Create playlists
- Rename playlists
- Delete playlists
- Add songs from inside a playlist
- Add a song to one or more playlists from the song details page
- Create a new playlist while adding a song
- Search songs while selecting them for a playlist

### Notes

The Notes section is for general notes that are not tied to a specific song.

Notes support:

- Create, edit, and delete
- Search
- Sort by date or title
- Pin important notes
- Multi-line text
- Images
- Last modified date

### Piano Tutorials

Piano Tutorials contains learning material for chords, scales, and the circle of fifths.

#### Chords

Chord tutorial items can include:

- Name
- Type
- Keys / notes
- Image
- Video
- Inversions
- Relative chord
- Notes
- Links
- Custom fields

Default chord material includes major, minor, diminished, seventh, and inversion examples where available.

#### Scales

Scale tutorial items can include:

- Name
- Type
- Keys / notes
- Formula
- Image
- Video
- Linked chord list
- Notes
- Links
- Custom fields

Default major and natural minor scales are included. Each scale can be linked to its related chord items, and those links can be edited.

#### Circle of Fifths

The Circle of Fifths tutorial section explains key relationships, movement by fifths, examples, images, notes, and links.

### Manage

The Manage section contains reusable items used across songs.

#### Tags

Tags help classify songs. A song can have multiple tags, and filters support songs with multiple tags.

#### Rhythms

Rhythms work as reusable items. Each rhythm can include:

- Name
- Optional section, such as Annual, Kiahk, Holy Week, Pascha, and others

Songs can contain multiple rhythm items, and each rhythm item can include multiple rhythms. The first rhythm item is treated as the primary rhythm shown on the main song card.

### Settings

Settings includes:

- Light, night, or system theme
- English and Arabic language options
- Keep screen awake option
- Database backup and restore
- Full backup and full restore
- PDF export
- About section with app metadata

## Media Handling

When you select local media, Melodiox copies the file into the app storage instead of only saving the original path.

This helps prevent broken media if the original file is moved or deleted.

Supported media includes:

- Images
- Chord images
- Melody images
- Audio
- Vocal-only audio
- Videos
- External links

## Backup And Restore

Melodiox supports two backup types.

### Database Backup

Database backup saves the app data such as songs, tags, rhythms, playlists, tutorials, notes, and settings.

Use this when you only need the app records.

### Full Backup

Full backup saves the database and copied media files.

Use this before uninstalling the app, moving to another phone, or protecting all images, audio, and video files.

### Restore

Restore replaces the current local library with the selected backup.

Full restore also restores copied media files.

Local and Google Drive options are available through the Android file picker. To use Drive, choose a Google Drive location when saving or selecting the backup file.

## PDF Export

Selected songs can be exported to PDF.

Before exporting, you can choose which song attributes to include, such as:

- Title
- Lyrics
- Musical notes
- Rhythm
- Scale
- Tempo
- Chords
- Notes
- Tags
- Quarter-toned keys

The PDF export supports Arabic text.

## Navigation

Melodiox supports normal back navigation:

- Use the back arrow shown on pages when available.
- Swipe from the left or right edge to go back.
- Android back returns to the previous app section before exiting.

## Language Support

The app currently supports:

- English
- Arabic

The selected language is remembered when the app is reopened.

## Good To Know

- The app is built to work offline.
- Your library is stored locally on your device.
- Full backup is the safest option when media files are important.
- Tutorial images are displayed to fit the screen area, with fullscreen zoom still available.
